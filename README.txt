# For My Princess ♡ — Princess Day Website

A responsive, romantic one-page website made for Upangsha, with the four photos you supplied.

## Open it
1. Extract `princess_day_surprise.zip`.
2. Open the `princess_day_surprise` folder.
3. Double-click `index.html` (Chrome/Edge recommended).

The site works locally; an internet connection is only needed for the optional Google Fonts.

## Put it online (free)
- Netlify: sign in at https://app.netlify.com/drop and drag the extracted folder onto the page.
- GitHub Pages: upload the folder contents to a repository and enable Pages in repository Settings.

Keep `index.html` and the `assets` folder together. Do not move the photos out of `assets`.
